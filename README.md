Система управления складом и заказами интернет-магазина

Абстрактные классы: Использование BaseProduct и BaseEntity для строгой структуры продуктов и сущностей.
Логирование: LogMixin для вывода информации о создании объектов.
Управление продуктами: Создание продуктов с валидацией цены (запрет нулевых/отрицательных цен, подтверждение снижения).
Специализированные продукты: Поддержка Smartphone и LawnGrass с дополнительными атрибутами.
Категории: Организация продуктов с поддержкой итерации и подсчетом общего количества.
Обработка дубликатов: Объединение одинаковых продуктов с увеличением количества и обновлением цены.
Заказы: Управление заказами с автоматическим расчетом итоговой стоимости.
Тестирование: Полный набор тестов для проверки всех аспектов функциональности.
Использование
Запуск кода:
Основная функциональность реализована в main.py. Пример использования:

python

Копировать
from src.main import Product, Smartphone, Category, Order

# Создание продукта
product = Product("Samsung Galaxy S23", "256GB, Серый", 180000.0, 5)
print(product)  # Вывод: Samsung Galaxy S23, 180000.0 руб. Остаток: 5 шт.

# Создание категории и добавление продукта
category = Category("Электроника", "Гаджеты и устройства")
category.add_product(product)
print(category)  # Вывод: Электроника, количество продуктов: 5 шт.

# Создание заказа
order = Order("Заказ 1", "Первый заказ", product, 2)
print(order)  # Вывод: Заказ: Заказ 1, Товар: Samsung Galaxy S23, Количество: 2, Итоговая стоимость: 360000.0 руб.

Обзор классов
BaseProduct (ABC):
Абстрактный базовый класс для продуктов.
Определяет обязательные атрибуты (name, description, price, quantity) и методы (price getter/setter, __str__).
LogMixin:
Миксин для логирования создания объектов с выводом имени класса и параметров.
Product:
Наследуется от LogMixin и BaseProduct.
Реализует управление продуктами с валидацией цены и методом new_product для обработки дубликатов.
Smartphone:
Наследуется от Product.
Дополнительные атрибуты: efficiency, model, memory, color.
LawnGrass:
Наследуется от Product.
Дополнительные атрибуты: country, germination_period, color.
BaseEntity (ABC):
Абстрактный базовый класс для сущностей (Category, Order).
Определяет атрибуты name, description и метод __str__.
Category:
Наследуется от BaseEntity.
Управляет списком продуктов, поддерживает итерацию и подсчет количества.
CategoryIterator:
Итератор для Category, обеспечивающий перебор продуктов.
Order:
Наследуется от BaseEntity.
Управляет заказами, включая продукт, количество и итоговую стоимость.
