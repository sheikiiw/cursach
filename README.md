Система управления складом интернет-магазина
Этот проект реализует систему управления складом для интернет-магазина, позволяющую создавать и управлять категориями товаров, продуктами (включая специализированные типы, такие как смартфоны и газонная трава) и заказами. Система разработана с использованием объектно-ориентированных принципов, включая наследование, полиморфизм и инкапсуляцию, и включает модульные тесты для проверки функциональности.

Возможности
Управление продуктами:
Базовый класс Product с атрибутами: название, описание, цена и количество.
Специализированные классы Smartphone и LawnGrass с дополнительными атрибутами.
Валидация цены и подтверждение при снижении цены.
Поддержка добавления продуктов с обработкой дубликатов через метод класса new_product.
Миксин LogMixin для логирования создания объектов.
Управление категориями:
Класс Category для группировки продуктов.
Отслеживание общего количества категорий и продуктов во всех экземплярах.
Расчёт средней цены продуктов в категории.
Итерируемый интерфейс для перебора продуктов в категории.
Управление заказами:
Класс Order для представления заказов клиентов с указанием продукта, количества и общей стоимости.
Строковое представление для удобного отображения деталей заказа.
Обработка ошибок:
Пользовательское исключение ZeroQuantityError для предотвращения добавления продуктов с нулевым количеством.
Валидация цены и типа продукта при добавлении в категории.
Проверка типов при выполнении операций, таких как сложение продуктов.
Тестирование:
Комплексные модульные тесты с использованием pytest для проверки функциональности всех компонентов.

Примечания
Система поддерживает добавление только объектов класса Product или его наследников в категории.
При снижении цены продукта требуется подтверждение пользователя.
Тесты покрывают инициализацию объектов, обработку ошибок, работу с категориями, заказами и итераторами.
