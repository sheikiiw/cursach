
Система управления складом интернет-магазина

Управление продуктами: Создание и управление продуктами с указанием названия, описания, цены и количества.
Контроль цены: Приватный атрибут цены с проверкой на запрет нулевых или отрицательных значений и подтверждением для снижения цены.
Специализированные продукты: Поддержка специфических типов продуктов, таких как Smartphone и LawnGrass, с дополнительными атрибутами.
Управление категориями: Организация продуктов в категории с поддержкой итерации.
Обработка дубликатов: Объединение дублирующихся продуктов путем увеличения количества и обновления цены, если новая выше.
Модульные тесты: Полный набор тестов с использованием pytest для проверки функциональност
Обзор классов
Product:
Базовый класс для всех продуктов.
Атрибуты: name, description, price (приватный), quantity.
Методы: Геттер/сеттер для цены, new_product для создания/объединения продуктов, строковое представление и сложение для вычисления общей стоимости.
Smartphone:
Наследуется от Product.
Дополнительные атрибуты: efficiency, model, memory, color.
LawnGrass:
Наследуется от Product.
Дополнительные атрибуты: country, germination_period, color.
Category:
Управляет набором продуктов.
Атрибуты: name, description, products (приватный список).
Поддерживает итерацию по продуктам, предоставляет количество продуктов и строковое представление.
CategoryIterator:
Класс итератора для Category, обеспечивающий итерацию по продуктам.
Тестирование
Проект включает полный набор тестов в test_main.py с использованием pytest. Тесты охватывают:

Инициализацию Product, Smartphone, LawnGrass и Category.
Проверку сеттера цены (запрет отрицательных цен, подтверждение снижения).
Сложение продуктов (только одного класса).
Обработку дубликатов в new_product.
Управление продуктами в категориях и итерацию.
